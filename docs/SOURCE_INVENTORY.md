# Source File Inventory

This portfolio was built from the coursework, lab notebooks, datasets and assessment guidance supplied for the AI Implementation module.

## Coursework source files

- Coursework 1 submission ZIP — used for the original notebook, report, visual outputs, raw/processed data and summary statistics.
- Coursework 2 submission ZIP — used for the final modelling notebook, report, processed data, model metrics, confusion matrices, ROC output, interpretability, threshold and calibration results.
- Telco Customer Churn dataset ZIP — used as the raw source dataset for the flagship project.

## Lab source files

- Lab 2 notebook + processed CSV — preprocessing exercise.
- Lab 7 notebook — K-means / hierarchical clustering exercise.
- Lab 8 notebook — decision-tree classification exercise.
- Lab 10 notebook — TensorFlow/Keras MNIST neural-network exercise.

## Guidance source files

- Coursework 1 and Coursework 2 assessment briefs.
- Lab instruction PDFs for preprocessing, clustering, decision trees and neural networks.

The university-authored briefs/instruction PDFs are used as context but are not republished. `docs/ASSESSMENT_MAPPING.md` records how the public portfolio maps to those requirements.
